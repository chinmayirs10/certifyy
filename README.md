# Certifyy: Event & Certificate Platform

> All-in-one platform for organising events, from registration to **verifiable digital certificates**.

🌐 **Live:** [certifyy.in](https://www.certifyy.in)
📈 **In production:** 2,000+ users · 1,500+ certificates issued · 8+ events

🔒 *Source code is private. A product demo is available on request.*

---

## ✨ What It Does

| | |
|---|---|
| 📝 **Event registration** | Individual and team registrations with custom forms and online payments |
| 🎟 **Tickets & check-in** | E-tickets by email and QR-code check-in at the venue |
| 🎨 **Certificate designer** | Visual drag-and-drop template editor for certificates and ID cards |
| ⚡ **Bulk certificates** | Generate and email certificates for all participants in one go |
| ✅ **Online verification** | Anyone can scan a certificate's QR code to confirm it's genuine |
| 💬 **Feedback & analytics** | Post-event feedback forms and an organiser dashboard |
| 👥 **Team access** | Multiple organisers with configurable permissions |

## 🛠 Tech Stack

| Layer | Technologies |
|---|---|
| **Frontend** | React · TypeScript · Tailwind CSS |
| **Backend** | Python · FastAPI |
| **Data & Cloud** | Firebase · AWS |
| **Deployment** | Vercel · Render · CI/CD |
